01 / Capacidades exploradas

Do evento operacional à decisão rastreável.

O AGIS-OS reúne componentes para modelar estados e automatizar tarefas de apoio à operação. A interface apresenta conceitos do sistema, não métricas de uma frota real.

⌁

Motor de estados operacionais

Explora transições explícitas entre representações, conhecimento, intenções e decisões, em vez de depender apenas de sinalizadores estáticos.

↗

Processamento assíncrono

Separa requisições da API de tarefas que podem ser executadas por workers dedicados.

⌖

Dados geoespaciais

Base para tratar coordenadas, agrupamento de rotas e decisões relacionadas à localização.

⇄

APIs autenticadas

Endpoints com autenticação baseada em JWT e organização de permissões por papéis e escopos.

▤

Persistência estruturada

PostgreSQL e migrações para manter os dados operacionais organizados e evolutivos.

◫

Ambiente reproduzível

Docker Compose e componentes separados para facilitar configuração e experimentação local.
